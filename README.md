# ProjectHouseOfMemories

2D-приключение в Godot 4.7: тёмный дом, хранящий воспоминания. Игрок
просыпается в запертой спальне и с единственным источником света
исследует комнату, находит скрытые надписи и собирает ключ.

## Особенности

- **Свет как главный инструмент.** Луч фонарика строит маску света
  прямо по геометрии комнаты: пятна, «проливы» на стыках стен, пола
  и мебели, а также настоящие 2.5D-тени от стола и торшера.
- **Скрытые надписи.** Часть истории написана на стенах и видна
  только под достаточным светом. Три надписи образуют пазл — их
  нужно найти в строгом порядке, тогда появится ключ.
- **Классическая квестовая механика.** WASD-передвижение, клики по
  предметам, диалоги-«мысли», инвентарь из 6 слотов.

## Управление

| Действие | Ввод |
|---|---|
| Передвижение | `W A S D` |
| Взаимодействие | ЛКМ по предмету (в пределах дистанции) |
| Открыть/закрыть инвентарь | `E` |
| Фонарик вкл/выкл | `F` (прицел — мышь) |
| Диалог: дальше / пропустить печать | ЛКМ / `Enter` / `Space` |
| Оверлей FPS | `F3` |

## Запуск

1. [Godot 4.7+](https://godotengine.org/download) (GL Compatibility,
   окно 1920×1080).
2. Открыть `project.godot` — главная сцена `scenes/levels/bedroom.tscn`.

## Состояние и планы

Готово: спальня целиком — освещение, скрытые надписи, пазл с ключом,
диалоги, инвентарь, мебель.

В планах (см. [docs/design.md](docs/design.md), раздел «Известные
упрощения и план»):

- дверь с замком под ключ и переход между уровнями;
- фонарик как подбираемый предмет;
- лут в ящиках стола;
- сценарная структура «памятей», звук, меню.
